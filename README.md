## 📌 Sobre a Disciplina

A disciplina explora os principais conceitos teóricos e práticos dos diferentes modelos de computação e estilos de codificação, comparando sintaxe, semântica, gerenciamento de estado, memória e casos de uso de cada paradigma.

### 🧠 Paradigmas Abordados
- [x] **Imperativo & Estruturado** *(ex: BASIC, C)*
- [x] **Orientado a Objetos (POO)** *(ex: C++, C#, Python, Ruby, JavaScript, Java)*
- [ ] **Funcional** *(ex: Haskell, Lisp, Scheme)*
- [ ] **Lógico / Declarativo** *(ex: Prolog)*
- [x] **Multiparadigma & Modernas** *(ex: Rust, Go, Python)*
